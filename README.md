# Nassau Candy Factory Reallocation & Shipping Optimization

## 📌 Project Overview

This project is an interactive Machine Learning and Data Analytics application
developed using Python and Streamlit.

The application analyzes Nassau Candy Distributor data and provides insights
for factory reallocation, shipping optimization, lead-time analysis and
business recommendations.

## 🎯 Objectives

- Analyze order and shipping data
- Perform Exploratory Data Analysis (EDA)
- Analyze shipping lead time by region
- Analyze sales by division
- Predict shipping lead time
- Simulate factory reallocation scenarios
- Generate optimization recommendations

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Machine Learning
- Data Visualization

## 📊 Key Features

### 1. Dashboard Overview
Provides an overall summary of:
- Total Orders
- Average Lead Time
- Total Sales
- Average Gross Profit
- Lead Time by Region
- Sales by Division

### 2. Exploratory Data Analysis
Analyzes:
- Orders by Ship Mode
- Orders by Region
- Sales distribution
- Shipping and operational patterns

### 3. Prediction
Uses Machine Learning techniques to predict shipping-related
outcomes based on available order and shipping features.

### 4. Factory Simulation
Allows users to simulate factory reallocation scenarios and
analyze the possible impact on lead time and profit.

### 5. Recommendations
Provides data-driven recommendations based on:
- Shipping speed
- Profit
- Destination region
- Product
- Ship mode
- Optimization priority
